FROM EXPERIMENT TO APPLICATION

不止一个数字。
也比较如何得到它。

Canteen Lab 在二阶段实验基础上，将同图双方案对比做成可保存、可追溯的 Web 应用。

01 / 方法

同一照片，相同换算口径

两种方案共用 24 类食材词表及营养表。传统方案提供检测与分割图，大模型方案保留结构化预测和原始回复。结果缺失或失败会明确提示，不按零热量计算。

02 / 证据

把回放与实时分析分开

内置样例回放来自修正标注后真实运行的二阶段实验。上传照片走实时模型推理；历史回放不会发起新模型请求，也不会被算作新实验。

03 / 边界

估重，仍然不是称重

单张照片无法可靠反映厚度、密度和被遮挡的食材。标定来自固定俯拍环境，不能直接外推到所有餐盘。本项目用于学习与演示，不作为医疗、饮食或营养决策依据。

04 / 使用

哪些场景适合哪种方法？

需要本地运行、框和掩膜时，可继续训练与优化传统模型；快速探索食材语义和原型时，多模态接口更方便，但需管理费用、联网依赖及输出波动。
