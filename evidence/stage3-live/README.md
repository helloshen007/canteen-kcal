# 三阶段实时链路原始结果

本目录保存两次实际上传产生的完整结果。两次任务均执行 YOLO-World＋SAM 和 DeepSeek API，各发生一次大模型请求，共两次；不是使用样例回放生成的预测。

| 目录 | 产生方式 | A 热量 | B 热量 |
|---|---|---:|---:|
| `api-run/` | 开发过程中经 nginx 的真实 HTTP 联调 | 78.3 kcal | 36.0 kcal |
| `browser-run/` | 基于 `f728814` 的浏览器真实上传，已录屏 | 78.3 kcal | 36.0 kcal |

每个目录包含：

- `input.jpg`：实际上传的照片，保留原始字节。
- `analysis.png`：A/B 共同读取的处理后图片；该样例本来即为 640×480，解码像素保持一致。
- `overlay.jpg`：实际 A 检测框与 SAM 掩膜叠加图。
- `a.json`、`b.json`：完整逐图结果；B 包含原始 `raw`、模型、提示词和请求尝试次数。
- `job.json`：浏览器接口返回的记录快照，不含账号密码、cookie 或服务密钥。
- `run.json`：数据版本、图片与代码摘要、文件摘要及调用来源。早期 API 联调注明开发工作树状态；浏览器联调注明对应的运行代码提交。

输入来自 `dish_1558027001`。修正后的源真值为西瓜 68g、20.4 kcal；本轮 A 将其误识别为草莓/覆盆子，B 识别西瓜但估重为 120g、36 kcal。这些误差如实保留。两条新任务用于证明 Web 实时链路，二阶段总体指标继续由 `evidence/revalidated/` 的 20 图、每图三次 B 结果复算。

运行环境、53 项本地/容器测试、浏览器操作及完整重启恢复记录见 [stage3-run.json](../../docs/stage3-run.json)，实际网页操作见 [三阶段视频](../../docs/stage3-video/README.md)。上述 JSON 和图片可离线核对，不需要 API 密钥。
