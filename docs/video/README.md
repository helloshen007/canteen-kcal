# 当前版本运行演示

[下载或播放 demo.mp4](demo.mp4)。2026-10-25 录制，约 43 秒，1440×1000，H.264，12 fps，无音轨。

视频直接记录实际运行的 Gradio 界面，通过浏览器切换固定测试图片，保留真实交互间隔。展示的图片、框、掩膜、真值与 A/B 预测来自本轮真实实验；没有重绘界面或修改展示数字。

| 时间 | 展示内容 |
|---|---|
| 0–6 秒 | 首张测试图，原图与检测分割、真值/A/B 三列并排；可见 A 的误识别。 |
| 6–16 秒 | `dish_1558027001`，西瓜修正为 68g、20.4 kcal；B 的估重与真值仍有差异。 |
| 16–27 秒 | `dish_1558028194`，含西瓜的混合食材，修正后可见真值为 172g、228.0 kcal。 |
| 27–37 秒 | `dish_1558028772`，另一张含西瓜混合食材图，可见真值为 192g、64.0 kcal。 |
| 37 秒至结束 | 返回首图，展示切换及结果恢复。 |

应用读取 `results/revalidated/` 的已保存预测和检测特征，录制期间未再次调用 API、未现场执行模型推理。因此视频展示运行界面与主要结果；模型和 API 的原始运行证据见 [逐图证据](../../evidence/revalidated/README.md)，全部样本的误差见 [结果表](../results.md)。播放器若无法在 GitHub 页面内播放，请下载原始 MP4。

复现同一演示：先按 [完整复现文档](../reproduction.md)准备原图及本轮特征/预测，然后运行：

```bash
python app.py --results-root results/revalidated
```

依次选择上表四张测试图即可。视频不展示密钥，也不代替本人对代码和基础概念的答辩。`recording.json` 记录实际交互时间、视频参数和文件哈希。
