## 验收边界

仓库材料和上述三项工程问题已完成复查。附件还要求本人理解代码、能够修改和排错，以及理解 Transformer 等概念；这些需要本人演示或答辩，自动测试无法代替。

实验仍有明确局限：原阈值曾参考测试集选择；样本仅为固定环境的 20 张测试图；估重不等于称重；西瓜名称修正依据 ID 关联、原图和营养值，未宣称访问了当时不可达的官方 GCS 原表。这些限制不因材料齐全而消失，也不能用本轮小样本指标保证实际食堂表现。

## 无密钥复查

在已安装依赖的仓库根目录运行：

```bash
python -m unittest discover -s tests -v
python -m compare.report --results-root evidence/revalidated --output results/revalidated/acceptance-report.md
```

以上两步无需 API 密钥；第二步也不需要模型权重和原图。完整从原始数据重跑需按复现文档下载数据、模型，并在本地配置 API。
