# 三阶段 Web 运行演示

[下载或播放 demo.mp4](demo.mp4)。2026-10-29 实录，约 62 秒，1440×1080，H.264 / 12 fps，无音轨，约 1.2 MB。若 GitHub 无法直接播放，请下载原始文件。

| 时间 | 内容 |
|---|---|
| 0–7 秒 | 展示本轮实际 Docker 启动输出、四服务健康状态和 API 就绪响应。为便于阅读，将命令输出放在浏览器日志页显示；原始文字见 [startup.txt](startup.txt)。 |
| 7–15 秒 | 打开工作台，选择餐盘照片并从网页提交实时分析。 |
| 15–31 秒 | 实际等待 Redis worker 执行 YOLO-World＋SAM 与 DeepSeek；页面轮询显示阶段和结果。 |
| 31–44 秒 | 展示 A/B 同图结果，并打开大模型原始回复。 |
| 44–51 秒 | 修改标题备注并查看持久化分析记录。 |
| 51 秒至结束 | 查看明确标记的历史回放，再返回本次真实分析结果。 |

录制中的上传确实调用了两种模型，其中大模型发出一次实际请求；对应的 [原始证据](../../evidence/stage3-live/browser-run/)保存输入、共同处理图、分割图、A/B 预测、raw 回复、模型配置和 SHA-256。A 的误识别及估重误差保留在画面中，没有修改显示数字。录制使用已登录的临时测试账号，不展示密码、会话令牌或 API 密钥。

`recording.json` 记录实际操作时间、运行代码提交、编码参数和视频摘要。视频记录真实浏览器视口，按截图原始时间间隔编码。模型准备、首次镜像构建和依赖下载见 [部署说明](../deployment.md)；启动片段来自这些准备完成后的本轮实际启动日志。云环境的代理覆盖配置放在仓库外，因此日志中的 `/tmp/canteen-stage3-cloud.yaml` 是本机配置，普通网络部署使用仓库的 `compose.yaml` 即可。

二阶段旧 Gradio 视频继续保存在 `docs/video/`，本视频对应新增的三阶段应用。照片与衍生演示资料来源、授权及改动见 [样例来源说明](../../web/examples/README.md)。
